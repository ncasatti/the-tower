# Testing (neotest)

Buffer-local in Python test files (`test_*.py`, `*_test.py`).

## Run

- `<leader>Tr` — Run nearest test
- `<leader>Tf` — Run test file
- `<leader>Ta` — Run all tests
- `<leader>Tl` — Run last
- `<leader>Ts` — Stop
- `<leader>Td` — Debug nearest (via DAP)
- `<leader>Tw` — Toggle watch

## UI

- `<leader>To` — Show output
- `<leader>TO` — Toggle output panel
- `<leader>TS` — Toggle summary

## Navigation

- `[T` — Jump to previous failed
- `]T` — Jump to next failed
