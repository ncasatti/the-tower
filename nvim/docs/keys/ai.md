# AI

OpenCode (chat / code generation) + Codeium (inline completion).

## OpenCode (`<leader>a*`)

### Quick
- `<leader>aa` — Toggle OpenCode panel
- `<leader>as` — Select model (normal / visual)
- `<leader>ai` — Ask (normal / visual)
- `<leader>aI` — Ask with context
- `<leader>ab` — Ask about current buffer

### Prompts (`<leader>ap*`)
- `<leader>ap` — Custom prompt
- `<leader>ape` — Explain selection
- `<leader>apf` — Fix selection
- `<leader>apd` — Diagnose selection
- `<leader>apr` — Review selection
- `<leader>apt` — Generate tests
- `<leader>apo` — Optimize selection

## Codeium (insert mode)

- `<C-y>` — Accept suggestion
- `<C-/>` — Trigger suggestions
- `<C-i>` — Next completion
- `<C-n>` — Previous completion
- `<C-x>` — Clear suggestions
