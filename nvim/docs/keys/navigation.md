# Navigation

Find files, jump between files, peek at definitions, and file explorer.

## Find (Snacks)

- `<leader><leader>` — Find files (cwd)
- `<leader>ts` — Smart find
- `<leader>tt` — Buffers
- `<leader>tc` — Find config file (`~/.config/nvim`)
- `<leader>tg` — Find git files
- `<leader>tp` — Projects
- `<leader>tr` — Recent (cwd)
- `<leader>tR` — Recent (global)

## Harpoon (file pins)

- `<leader>ta` — Add current file
- `<leader>th` — Open harpoon menu
- `<leader>ty` — Clear all pins
- `<leader>1` / `<leader>2` / `<leader>3` / `<leader>4` — Jump to pin 1-4
- `<leader>tu` — Previous pin
- `<leader>tn` — Next pin

## File explorer (Oil)

- `-` — Open Oil (floating, parent dir)
- `<leader>E` — Open Oil (parent dir of current file)

## Goto Preview (peek definitions)

- `gpp` — Preview definition
- `gpt` — Preview type definition
- `gpi` — Preview implementation
- `gpr` — Preview references
- `gpz` — Close all preview windows
