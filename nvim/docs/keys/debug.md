# Debug (DAP)

Java, Kotlin, Python, JS/TS via vscode-js-debug.

## F-keys (traditional debugger)

- `<F5>` — Continue
- `<F6>` — Pause
- `<F9>` — Toggle breakpoint
- `<F10>` — Step over
- `<F11>` — Step into
- `<F12>` — Step out

## Breakpoints & flow

- `<leader>db` — Toggle breakpoint
- `<leader>dB` — Set conditional breakpoint
- `<leader>dc` — Continue
- `<leader>dC` — Run to cursor
- `<leader>di` — Step into
- `<leader>do` — Step over
- `<leader>dO` — Step out
- `<leader>dl` — Run last
- `<leader>dt` — Terminate

## Inspection

- `<leader>dr` — Toggle REPL
- `<leader>du` — Toggle DAP UI
- `<leader>de` — Evaluate expression (normal + visual)
- `<leader>dh` — Hover variables
- `<leader>dp` — Preview variable

## Python-specific (buffer-local in `.py` files)

- `<leader>dtn` — Debug test method
- `<leader>dtc` — Debug test class
- `<leader>ds` — Debug visual selection (visual mode)
