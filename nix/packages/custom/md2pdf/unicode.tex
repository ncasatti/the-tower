% md2pdf: Unicode → LaTeX map for pdflatex.
% pdflatex/inputenc only knows a Unicode subset; agent-written docs carry
% −, ✓, ✗, box-drawing, emoji, … which abort the build with
% "Unicode character X not set up for use with LaTeX". Mapping them here
% keeps the engine (and Latin Modern) instead of switching to lualatex,
% which would change metrics and silently drop glyphs the font lacks.
%
% Adding a char: one \DeclareUnicodeCharacter{<HEX>}{<latex>} line.
